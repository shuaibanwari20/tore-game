# توره (TORE) — بازی ورق آنلاین چهارنفره

بازی تیمی «توره» با قانون قندهاری: ۴ بازیکن، ۲ تیم (بازیکن‌های روبه‌رو هم‌تیمی‌اند)،
هر دست ۳۰ **تاوان** دارد، برندهٔ هر دست ۲۰ و بازنده ۱۰ امتیاز می‌گیرد و مسابقه تا **۲۱۰** است.

## قانون امتیاز (تاوان)

| ورق | تاوان |
|---|---|
| هر ورق لال ♥ (دل) | ۱ — جمعاً ۱۳ |
| غلام پشه — سرباز گشنیز (J♣) | ۵ |
| ماتکه کالا — بی‌بی پیک (Q♠) | ۹ |
| ده خشت (10♦) | ۳ |
| **جمع هر دست** | **۳۰** |

- برندهٔ دست (تیمی که تاوان کمتری گرفته) **۲۰** امتیاز می‌گیرد، تیم دیگر **۱۰**.
- اگر تاوان‌ها ۱۵–۱۵ شد، تیمی که **ماتکه کالا** را گرفته بازندهٔ دست است (۱۰ در برابر ۲۰).
- بازی بدون حکم (ترومپ) است؛ بزرگ‌ترین ورقِ رنگِ آغازشده، دستک (تریک) را می‌برد و همان بازیکن دستک بعدی را شروع می‌کند.

## راه‌اندازی

نیازمندی: Node.js نسخهٔ ۲۰.

```bash
cd ~/workspace/projects/tore-game
npm install        # فقط بار اول (بستهٔ ws)
npm start          # سرور روی پورت 3000
```

پورت را می‌توانی عوض کنی:

```bash
PORT=8080 npm start
```

بعد در مرورگر گوشی یا کمپیوتر برو به:

```
http://localhost:3000
```

(از گوشی‌های دیگر در همان شبکه: `http://<IP-کمپیوتر>:3000`)

## طرز بازی

1. یک نفر «ساختن اتاق تازه» را می‌زند و **کد ۴ حرفی** اتاق را به دوست‌هایش می‌دهد.
2. دوست‌ها نام خود را نوشته، کد را وارد می‌کنند و «ورود به اتاق» را می‌زنند (جمعاً ۴ نفر؛ دو نفر روبه‌رو هم‌تیمی‌اند).
3. میزبان «شروع بازی» را می‌زند — جای‌های خالی خودکار با **ربات** پر می‌شود.
4. اگر اتصال کسی قطع شد، صندلی و ورق‌هایش **۱۲۰ ثانیه** نگه داشته می‌شود و با باز کردن دوبارهٔ صفحه، به همان صندلی برمی‌گردد.
5. اگر نوبت کسی ۳۰ ثانیه طول کشید، ربات به‌جایش یک ورق قانونی بازی می‌کند تا بازی نایستد.

## تست خودکار قانون‌ها

```bash
npm run sim        # یا: node sim.js 24
```

۲۴ مسابقهٔ کامل ربات‌به‌ربات با همان موتور قانون‌های سرور (`game.js`) بازی می‌شود و
همه‌چیز بررسی می‌گردد: ۵۲ ورق سالم، ۱۳ ورق برای هر کس، جمع تاوان هر دست دقیقاً ۳۰،
امتیاز هر دست همیشه ۲۰/۱۰، قانون مساوی ۱۵–۱۵ با ماتکه کالا، و پایان مسابقه دقیقاً در ۲۱۰.
